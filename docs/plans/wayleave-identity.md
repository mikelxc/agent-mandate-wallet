# Wayleave: calm autonomy

The approved emotional references are Stoic and Waymo. The product premise is one owner funding wallet, independently identifiable agent wallets, explicit payment approval, and a shared view of spending.

The identity uses a continuous rounded W with a central dot: separate paths supported by one base. Reusable monochrome geometric agent illustrations, mist-gray backgrounds, white surfaces, soft corners and dark primary controls give the interface a personal, quiet character. The landing illustration is interactive and explicitly labeled as an example; it does not claim real balances or payments.

The identity extends through onboarding, payment surfaces, navigation, WalletConnect appearance, SVG/ICO favicon, install icons and social preview. Motion is brief and state-driven; reduced-motion preferences disable animations and transitions. No signing, allowance, gateway or contract behavior changes in this design release.
